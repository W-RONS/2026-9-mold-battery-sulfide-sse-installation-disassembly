# 第二部分：匀浆涂布

## 记录说明

本页面用于记录电极浆料的匀浆、涂布及后续处理。本记录针对手动制备小样本的过程，具体配方、参数和设备程序以实际实验记录为准。

## 实验目的

在集流体上进行匀浆涂布，制备模具电池所需的电极片。

## 1. 浆料制备

### 1.1 准备匀浆管

准备匀浆管。使用时，匀浆管的实际使用容量不应接近其容量上限，应为后续加入金属小球和摇匀过程留出空间。

### 1.2 称量并加入原料

1. 按照预先准备好的配方，称量所需的各种物质。
2. 将称量好的物质依次放入匀浆管。
3. 对于液体原料，使用移液枪时注意移液枪的量程；按压移液枪时不要触底，并注意避免污染原料。
4. 确认目标物质均已加入匀浆管后，在匀浆管内放入用于摇匀的金属小球。

### 1.3 密封、修剪与摇匀

1. 将加入原料和金属小球的匀浆管密封。
2. 密封后按照实际装置要求对匀浆管进行修剪处理。
3. 将处理好的匀浆管放到摇匀用的球磨机器上。
4. 启动机器，按照预设时间和制定程序进行摇匀。
5. 如果程序中设置了摇匀等待间隔，应按照程序完成间隔，以进行散热。

### 1.4 产物

摇匀流程完成后，获得电极浆料。

## 2. 涂布操作

### 2.1 加热装置与镜面平板准备

1. 启动加热装置，并预热至预设温度。
2. 取出镜面平板，检查平面是否平整、洁净；如发现不平整或有污渍，先对平面进行清洁。

### 2.2 集流体选择与裁剪

1. 取出集流体薄膜，按照操作前的预设进行选择。可选集流体包括涂炭铜和镀镍铜。
2. 将集流体平铺在镜面平板上。
3. 根据目标涂布厚度选择涂布工具。
4. 按照涂布工具的工作宽度裁剪集流体，使裁剪后的集流体片宽度略小于涂布工具的工作宽度。

### 2.3 集流体固定与工具检查

1. 将裁剪好的集流体平铺在镜面平板上。
2. 使用标签或胶带将集流体固定平整。
3. 检查涂布工具能否在集流体表面无阻碍地滑过。

### 2.4 浆料放置与分散

1. 将涂布工具放在涂布准备位置。
2. 在涂布工具前方、集流体宽度方向的中间位置，倒入前面配置好的浆料。
3. 取出浆料中用于摇匀的金属小球。
4. 使用称量勺或其他工具，将浆料沿涂布工具前沿进行分散。
5. 分散时不要过度靠近集流体边缘，尽量使浆料在涂布工具前方均匀堆积。

### 2.5 单次涂布

1. 使用双手缓慢、匀速地拉动涂布工具，使其在集流体表面完成涂布。
2. 涂布尽量一次完成，不反复在集流体表面来回滑动。
3. 涂布完成后，观察涂布表面是否平整、均匀。

### 2.6 烘干与收样

1. 将贴有涂布后集流体的镜面平板放置在预热好的加热装置上，使浆料中的溶剂烘干、蒸发。
2. 在等待烘干的过程中，使用纸巾清理涂布工具。
3. 等待预设时间后，观察涂布区域是否干燥，并检查溶剂是否充分蒸发。
4. 确认完成后，收取制备好的样品。

## 3. 干燥与后续处理

涂布后的集流体在预热好的加热装置上进行烘干，使浆料中的溶剂蒸发。具体预设温度、等待时间、干燥状态及后续处理结果待补充。
